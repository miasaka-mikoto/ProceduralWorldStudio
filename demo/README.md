# Export samples

`demo/coastal_city/` is regenerated by `scripts/generate_demo.py` and is safe to replace.  `demo/hills_town/` is an alternate fixed-seed preset (Hills + Organic roads).  Both are deliberately included as small, inspectable demonstrations of the complete pipeline rather than screenshot-only artifacts.

| File | Use |
| --- | --- |
| `world.json` | Editable canonical world state and generator history |
| `world.geojson` | GIS/feature inspection |
| `world.png` | Top-down screenshot/preview |
| `editor_screenshot.png` | Off-screen smoke capture of the editable desktop UI |
| `editor_screenshot_isometric.png` | Isometric camera smoke capture |
| `world.obj` | Basic geometry import |
| `world.gltf` | Basic geometry import for modern engines |
| `manifest.json` | Seed, version, counts, and JSON hash |

Regenerate the canonical coastal demo with:

```powershell
python scripts/generate_demo.py --output demo/coastal_city
```

Regenerate the alternate hills demo with:

```powershell
python scripts/generate_demo.py --seed 31415 --terrain hills --road-pattern organic --output demo/hills_town
```
